# 位置模式修复说明

## 问题
用户输入 `set 1 10 10` 期望电机从当前位置移动10mm，但实际移动距离不对。

## 根本原因
DJI电机使用**绝对位置模式**：
- 发送的position值是目标绝对位置（编码器计数）
- 如果电机当前在50mm，发送10mm，电机会反向移动到10mm

## 解决方案
修改为支持**相对移动模式**（默认）和**绝对位置模式**：

### 新命令

1. **相对移动**（默认，推荐）
```bash
>>> set 1 30 10      # 从当前位置向前移动10mm
>>> set 1 30 -5      # 从当前位置向后移动5mm
```

2. **绝对位置**
```bash
>>> moveto 1 30 100  # 移动到绝对位置100mm
```

3. **重置位置**
```bash
>>> reset 1          # 重置电机1的位置计数为0
```

### 实现方式
- 内部维护累计位置（current_position）
- 相对移动：position += 增量
- 绝对位置：position = 目标值

### 参数变化
- `set_motor(..., relative=True)` - 默认相对移动
- `set_motor(..., relative=False)` - 绝对位置

现在 `set 1 10 10` 会正确地从当前位置移动10mm！
