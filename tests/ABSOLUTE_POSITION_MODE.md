# 绝对位置模式说明

## ✅ 已改为绝对位置模式（默认）

### 修改内容
1. `set_motor()` 函数默认参数：`relative=False`（原来是True）
2. `set` 命令：现在是绝对位置
3. 新增 `move` 命令：用于相对移动

### 使用方法

#### 绝对位置（默认）
```bash
>>> set 1 30 10      # 移动到绝对位置10mm
>>> set 1 30 20      # 移动到绝对位置20mm
>>> set 1 30 5       # 移动到绝对位置5mm（会反向）
```

#### 相对移动（需要时）
```bash
>>> move 1 30 10     # 从当前位置向前移动10mm
>>> move 1 30 -5     # 从当前位置向后移动5mm
```

### 测试结果
```
第1次: set 1 10 10  → 位置: 55212 (10mm)   ✓
第2次: set 1 10 20  → 位置: 110425 (20mm)  ✓
第3次: set 1 10 5   → 位置: 27606 (5mm)    ✓
```

### 换算参数（包含36:1减速比）
- 轮子直径: 17mm
- 圆周长: 53.41mm
- 编码器分辨率: 8191 计数/圈
- 减速比: 36:1
- 换算系数: 5521.29 编码器计数/mm
- **10mm = 55212 编码器计数**

现在 `set 1 30 10` 会移动到绝对位置10mm！
