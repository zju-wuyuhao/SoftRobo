# 实时控制系统使用指南

## 启动程序
```bash
python3 realtime_control.py
```

## 命令说明

### 系统控制
- `start` - 启动实时控制系统
- `stop` - 停止系统
- `quit` / `exit` - 退出程序

### 电机控制（推荐使用相对移动）

#### 相对移动（默认模式）
```bash
>>> set 1 30 10      # 电机1以30RPM从当前位置向前移动10mm
>>> set 1 30 -5      # 电机1以30RPM从当前位置向后移动5mm
>>> set 2 20 15.5    # 电机2以20RPM移动15.5mm
```

**优点**：
- 符合直觉：输入10就移动10mm
- 可以累加：多次执行会持续移动
- 支持正负：正数前进，负数后退

#### 绝对位置（需要时使用）
```bash
>>> moveto 1 30 100  # 电机1移动到绝对位置100mm
>>> moveto 2 20 50   # 电机2移动到绝对位置50mm
```

#### 位置重置
```bash
>>> reset 1          # 重置电机1的位置计数为0
```

### 启用/禁用
```bash
>>> enable 1         # 启用电机1（开始运动）
>>> disable 1        # 禁用电机1（停止）
>>> enable_all       # 启用所有6个电机
>>> disable_all      # 禁用所有电机
```

### 状态查看
```bash
>>> status           # 显示所有电机状态
```

## 完整使用流程示例

```bash
# 1. 启动系统
>>> start

# 2. 设置电机1从当前位置移动10mm
>>> set 1 30 10

# 3. 启动电机1
>>> enable 1

# 4. 查看状态
>>> status

# 5. 再移动5mm
>>> set 1 30 5

# 6. 停止电机
>>> disable 1

# 7. 关闭系统
>>> stop
```

## 位置换算
- 轮子直径: 17mm
- 圆周长: 53.41mm
- 1mm ≈ 153.4 编码器计数

## 注意事项
1. 默认使用相对移动模式，更符合实际使用习惯
2. 如需精确控制绝对位置，使用 `moveto` 命令
3. 使用 `reset` 可以重置位置计数
4. 相对移动会累加，多次执行会持续移动
