# 电机到达目标后抖动问题

## 问题描述
电机运动完成后会左右轻微抖动

## 原因分析

### 1. 持续发送位置命令
当前实现每0.1秒持续发送位置命令，即使电机已到达目标：
```python
while self.running:
    for motor in enabled_motors:
        send_position_command(motor.position)  # 持续发送
    time.sleep(0.1)
```

### 2. 控制器响应
- 电机控制器接收到位置命令
- 检测当前位置与目标位置的误差
- 即使误差很小（如±1-2个编码器计数），仍会尝试修正
- 修正过程中产生超调
- 形成振荡

### 3. 为什么需要持续发送？
- DJI电机有**超时保护**（3-5秒无命令会停止）
- 持续发送是为了防止超时

## 解决方案

### 方案1: 到达目标后降低发送频率（推荐）
```python
# 到达目标：每1秒发送1次（保持不超时）
# 运动中：每0.1秒发送1次（快速响应）
```

### 方案2: 到达目标后发送速度0
```python
# 位置模式到达后，切换为速度模式，RPM=0
# 电机会保持当前位置，但不会微调
```

### 方案3: 添加死区（Deadband）
```python
# 只在误差>阈值时才认为"未到达"
# 减少不必要的微调
```

### 方案4: 禁用电机
```python
# 到达目标后，直接disable
# 最简单，但会失去保持力
```

## 建议实现

结合方案1和方案3：
- 检测电机是否到达目标（通过反馈或时间估算）
- 到达后降低发送频率到1Hz
- 这样既不超时，又减少振荡
